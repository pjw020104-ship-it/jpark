# 한화그룹 신입 채용 직무안내 챗봇

한화그룹 신입 지원자에게 계열사·직무별 실무 내용을 안내하는 대화형 챗봇 프로토타입입니다.
자세한 기능 스펙은 `SPEC.md`를 참고하세요.

## 구성

- `backend/` — Node.js/Express API 서버 (LLM: Google Gemini API)
- `frontend/` — React + Vite 프론트엔드
- `data/` — 계열사·직무 데이터 (`organizations.json`, `company_jobs.json`)
- `tests/` — Vitest 테스트

## 필요 프로그램 (다른 컴퓨터에서 처음 설치 시)

- **Node.js 18 이상**: https://nodejs.org 에서 LTS 버전 설치 (설치 후 터미널에서 `node --version`으로 확인)
- **Gemini API 키**: https://aistudio.google.com/apikey 에서 발급 (무료 티어 있음, 사용량에 따라 과금될 수 있습니다)

## 실행 방법

### 1) 백엔드 실행

`backend/.env.example`을 복사해 `backend/.env`를 만들고 발급받은 키를 입력합니다:
```
GEMINI_API_KEY=여기에_발급받은_키를_입력하세요
PORT=3001
```

그 다음 서버를 실행합니다.
```
cd backend
npm install
npm run dev
```
`백엔드 서버 실행 중: http://localhost:3001` 메시지가 뜨면 정상입니다.

### 2) 프론트엔드 실행 (새 터미널 창에서)

```
cd frontend
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 (백엔드 API는 자동으로 프록시됩니다).

### 3) 테스트 (선택)

```
npm install
npm test
```

## 나의 역량 진단하기 — 포트폴리오 첨부

역량 진단 화면에서 자기소개서를 붙여넣는 것과 별개로, 포트폴리오를 **PDF · DOCX · PPTX 파일로 첨부**할 수 있습니다.

- 첨부한 파일은 **서버로 올라가지 않습니다.** 브라우저에서 텍스트만 뽑아 분석에 사용하고, 원본 파일은 PC를 벗어나지 않습니다.
- 뽑아낸 내용은 자기소개서와 함께 선택한 회사·직무 기준으로 분석되며, 결과에 **직무 적합도 점수(0~100)** 와 강점·부족한 역량·핵심 역량 평가·자소서 강조 경험·면접 예상 질문이 나옵니다.
- 첨부 파일에서 근거를 찾은 항목에는 `(근거: 포트폴리오.pdf p.3)`처럼 **파일명과 쪽수**가 함께 표시됩니다. PDF는 쪽 번호, PPTX는 슬라이드 번호가 쓰이고, DOCX는 파일에 쪽 정보가 없어 파일명만 표시됩니다.
- 손상됐거나 암호가 걸린 파일, 글자 없이 이미지로만 스캔된 문서는 읽을 수 없습니다. 그런 파일은 목록에 오류로 표시되고 나머지 파일로 분석은 계속됩니다.
- 파일당 15MB, 30,000자까지 사용합니다. 분량이 넘으면 앞부분만 쓰고 그 사실을 표시합니다.

## 직무 이슈 분석 — 뉴스 검색 기반

"직무 이슈 분석"은 Google 검색으로 **실제 보도된 뉴스**를 찾아 정리합니다.

- 각 이슈에 **보도 매체와 보도 시점**이 함께 표시됩니다 (확인되지 않으면 표시하지 않습니다).
- 결과 아래 **출처** 토글을 펼치면 참고한 기사 원문 링크가 모두 나옵니다.
- 링크는 모델이 쓴 것이 아니라 검색 결과에서 받은 실제 URL만 씁니다. 검색이 안 되면 지어내는 대신 "검색하지 못했습니다"로 안내합니다.
- 검색과 정리를 나눠서 **Gemini를 2번 호출**합니다. 다른 기능보다 응답이 느리고 API 사용량도 2배입니다.

## 알려진 한계

- **"직무 설명"은 실시간 검색을 하지 않습니다**: 통상적인 채용공고(JD) 패턴을 바탕으로 답합니다. 화면에 그 사실이 안내 문구로 표시됩니다. ("직무 이슈 분석"은 아래처럼 실제 뉴스를 검색합니다.)
- **API 사용량에 따라 비용이 발생**할 수 있습니다 (Gemini 무료 티어 한도 초과 시).
- **세션은 서버 메모리에만 저장**되며 서버 재시작 시 초기화됩니다 (프로토타입 단계).
- **스캔 PDF는 읽지 못합니다.** 글자 정보가 없는 이미지 문서는 OCR이 필요한데 지원하지 않습니다.

## 배포 (웹사이트로 공개하기)

지금 구조(React 프론트 + Express API)는 그대로 배포 가능합니다.
- **백엔드**: Render/Railway 등에 `backend/`를 올리고 환경변수에 `GEMINI_API_KEY`를 설정합니다.
- **프론트엔드**: `npm run build`로 정적 파일을 만들어 Vercel/Netlify 등에 올리거나, 백엔드와 같은 서버에서 서빙합니다.
- `GEMINI_API_KEY`는 절대 프론트엔드 코드나 git에 커밋하지 말고, 배포 플랫폼의 환경변수로만 설정하세요.
