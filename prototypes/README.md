# prototypes/

실제 앱(`frontend/`)에 넣기 전에 따로 만들어 보는 UI 프로토타입 모음. **빌드/배포에는 포함되지 않는다.**

## intro-slideshow.html — 업종 인트로 슬라이드쇼

현재 앱의 인트로(`frontend/src/components/IntroSplash.tsx`, 로고 한 장 페이드아웃)를 대신할 후보.
한화의 주요 사업 업종을 순차적으로 보여준 뒤 로고로 수렴하고 사라진다.

```
방산 → 에너지 → 금융 → 호텔 → (로고 + 카피) → 페이드아웃 → 앱 화면
```

### 보는 법

파일을 더블클릭해서 열면 된다. 브라우저가 로컬 파일 제약으로 폰트/이미지를 막으면:

```
node prototypes/serve.mjs      # → http://localhost:4180
```

화면 왼쪽 아래 `PROTOTYPE` 바에서 **다시 재생** / **속도(0.5x·1x·2x)** 를 조절할 수 있다.
이 바와 오른쪽 위 "건너뛰기" 버튼은 검토용이며, 실제 적용 시 조작 바는 뺀다.

### 만들어진 방식

- **슬라이드당 1.9초**(크로스페이드 포함), 아웃트로 1.9초 → 전체 약 9.5초. `<script>` 맨 위의
  `SLIDE_MS` / `OUTRO_MS` / `FADE_MS` 상수만 고치면 길이가 바뀐다. CSS의 `--fade`는 `FADE_MS`와 같이 맞출 것.
- 업종마다 **옅은 배경 톤과 강조색**을 따로 주되(`방산` 스틸블루 / `에너지` 그린 / `금융` 인디고 / `호텔` 브론즈),
  하단 진행바와 마지막 로고에는 한화 오렌지(`#ff6a00`)를 공통으로 남겨 브랜드 축을 유지했다.
- 배경은 기존 스플래시와 같은 **흰색 계열**을 유지했다.
- 업종 그림은 외부 이미지 없이 **인라인 SVG 선화**로 그렸다(레이더/궤적, 태양+풍력, 상승 차트, 아치+파도).
- 텍스트는 `--d` 커스텀 프로퍼티로 **시차 등장**시킨다. `prefers-reduced-motion`이면 모션을 끈다.
- 아무 데나 클릭하거나 키를 누르면 건너뛴다.

### 폰트

`hanwha-fonts.css`는 **자동 생성 파일**이다. 로컬 파일로 열어도 한화 전용 폰트가 보이도록
`frontend/src/assets/fonts/hanwha/*.woff2`를 data URI로 인라인해 둔 것(약 875KB).
원본 폰트가 바뀌면 프로젝트 루트에서 다시 생성한다.

```
node prototypes/build-fonts.mjs
```

실제 앱에 옮길 때는 이 파일이 필요 없다 — `frontend/src/index.css`의 `@font-face`가 이미 같은 폰트를 등록한다.

### 실제 앱에 옮길 때

`IntroSplash.tsx`를 이 마크업/타이밍으로 바꾸고, 스타일은 `App.css`의 `.intro-splash` 블록을 대체하면 된다.
슬라이드 데이터(업종명·영문·설명·색·SVG)는 컴포넌트 안의 배열로 빼는 게 깔끔하다.
인트로가 9.5초는 길다고 판단되면 `SLIDE_MS`를 1200~1400 정도로 줄이는 걸 먼저 검토할 것.
